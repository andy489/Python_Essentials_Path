# Object-Oriented Programming

A series of Jupyter notebooks exploring Object-Oriented Programming in Python from first principles.

## Notebooks

| # | Notebook | Topics |
|---|----------|--------|
| 01 | [From Dictionaries to Objects](01-from-dict-to-obj.ipynb) | Lists, maps, designing a class, class vs object |
| 02 | [Custom Classes](02-custom-classes.ipynb) | Class definition, constructors, instance methods, dunder methods, underscore rules |
| 03 | [Attributes and Properties](03-attributes-and-properties.ipynb) | Instance vs class attributes, properties, getters/setters, class methods |
| 04 | [Building Class Relationships](04-building-class-relationships.ipynb) | Associations, aggregation, composition, inheritance |
