# Data Structures

A series of Jupyter notebooks covering Python's core data structures from the ground up.

## Notebooks

| # | Notebook | Topics |
|---|----------|--------|
| 01 | [Using Lists](01-using-lists.ipynb) | List creation, indexing, slicing, mutation, sorting, comprehensions |
| 02 | [Working with Tuples](02-working-with-tuples.ipynb) | Immutability, packing/unpacking, named tuples |
| 03 | [Mapping with Dictionaries](03-mapping-with-dictionaries.ipynb) | Key-value pairs, iteration, merging, comprehensions |
| 04 | [Utilizing Sets](04-utilizing-sets.ipynb) | Uniqueness, set operations, frozensets |
| 05 | [Using Specialized Collections](05-using-specialized-collections.ipynb) | Counter, defaultdict, OrderedDict, deque, namedtuple |
